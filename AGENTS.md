## iKanban board skill

This project uses iKanban. AI agents can manage the board directly by following the portable skill in `.agents/skills/ikanban/SKILL.md`. The skill explains how to create, update, move, reorder and remove tasks while preserving timestamps and YAML validity.

Run `iKanban: Install AI Skill` to refresh the skill.
